# Freelancer Ihsan — 3D Game Portfolio

A game-style 3D portfolio website for Freelancer Ihsan.

## Features
- 3D explorable world
- Driveable car
- WASD / Arrow key controls
- Space = boost
- E = open nearby location
- About Me, Services, Projects and Contact zones
- Mini map
- Animated lighting, fog and 3D environment
- Mobile touch controls
- GitHub Pages compatible

## Run
Simply open `index.html` through a local server, or upload the whole folder to GitHub Pages.

For GitHub Pages:
1. Create a repository.
2. Upload all files and the `assets` folder.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → root.
5. Save.

The 3D engine is loaded from Three.js CDN, so the site needs internet access when viewed.
