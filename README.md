# Md Ihsan Ahmad | Portfolio Island

A unique drivable, game-style portfolio island.

## Controls
- Desktop: WASD to drive/move, E to enter zones, Space to boost.
- Mobile: touch joystick, Drive, Enter, Jump and Boost buttons.

## GitHub Pages
Upload all files to the repository root with `index.html` at the top level, then enable GitHub Pages from the `main` branch and `/ (root)`.

The project uses Three.js from jsDelivr, so the published site needs internet access.
